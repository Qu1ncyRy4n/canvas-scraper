Canvas Course Saver

Saving courses

  1. Open Canvas and log in (any page works).
  2. Click this icon, tick the courses you want, then Download.
  3. Keep the Canvas tab open until the box in its corner says Done.

Where things go

"Canvas" below is the folder name set under "Save to Downloads/".

  • Downloads/Canvas/Plaintext: text versions of everything. Drag a course folder (or its course.md) into NotebookLM, Claude or ChatGPT.
  • Downloads/Canvas/Source: the original PDFs, slides and files.
  • Each course has README.md (start here), CHANGES.md (what's new) and SKIPPED.md (what wasn't downloaded, and why).

Staying up to date

  • Click Download again any time. Only new or changed things download.
  • Once a day Canvas will ask Update your Canvas downloads?
  • Deleted a file by accident? The next update brings it back. Files you edit are left alone.

Text versions and transcripts

  • With the checkbox on, PDFs and slides get text versions and YouTube videos get transcripts right after each download. The corner panel shows the progress.
  • This needs the canvas-process helper. If the popup says not set up, run once in Terminal: canvas-process --install-browser-link, then reload the extension.

YouTube videos

  • Every YouTube link gets a (transcript) link next to it. All of them are in Plaintext/<Course>/transcripts, listed by title in its README.md.
  • Transcripts are made by canvas-process on this computer. If the links don't open, run canvas-process --check in Terminal.
  • In NotebookLM you can also paste the links from videos.md as YouTube sources.

Problems?

  • A save dialog for every file: turn off "Ask where to save each file" in the browser's download settings.
  • "Open your Canvas site": this tab isn't a logged-in Canvas page.

Everything stays on this computer. The extension only talks to your Canvas site.
